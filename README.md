# Morning_Board
The application will pull data from many platforms and present it into one dashboards. The platforms include Slack, School Canvas sites, Bank information, weather information, and CRM information.

There will be 3 development branches
Frontend_Dev
Backend_Dev
QA_Dev

Do not make pull request to any other branch besides one of these 3. 

Each Jira ticket will have it's own branch that will be branched off of one of the Dev branches (Which dev branch depends on what is being implimented)
